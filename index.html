Primera vez: la clave

El editor necesita una clave de GitHub. Se hace una sola vez: después te doy un link privado que ya la trae adentro, y con ese link entran vos y el equipo sin cargar nada.

  1. Abrir GitHub para crear la clave
    Se abre con todo completo (nombre, sin vencimiento y permisos). Si te pide iniciar sesión, entrá con la cuenta de Container.
  2. En Repository access elegí Only select repositories y marcá container-notas.
  3. Abajo de todo tocá Generate token y copiá la clave (empieza con github_pat_).
  4. Volvé acá, pegala y tocá Entrar.

Tu link privado

Este link ya trae la clave: guardalo en favoritos y en la pantalla de inicio del celular, y pasáselo a quien tenga que editar la revista. Con él se entra directo, sin cargar nada. Quien tenga el link puede editar, así que compartilo solo con el equipo.

Edición

Tocá cualquier título o bajada sobre la página y escribí. La revista sale tal cual la ves.
